# Bike Rental Demand Prediction

A beginner-friendly machine learning project using the real UCI Bike Sharing daily dataset (`day.csv`).

## What it does

- Checks and cleans the data
- Explores monthly, seasonal and working-day rental patterns
- Predicts daily rental counts using Linear Regression, Decision Tree and Random Forest
- Compares models using MAE and R²
- Prints the best model and key results automatically

## Run in Google Colab

1. Download the Bike Sharing dataset from https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset and extract `day.csv`.
2. Upload `Bike_Rental_Demand_Prediction.ipynb` to Colab.
3. Run the upload cell and select `day.csv`.
4. Run all cells in order.

## Note

This dataset covers bike-sharing activity in Washington, D.C. during 2011–2012. Results may not generalize to other cities or years.
